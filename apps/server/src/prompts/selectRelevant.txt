STEP 1 — READ THE INTELLIGENCE BRIEF & STRATEGY

STEP 2 — EXPERIENCE BULLET SELECTION
For each experience entry, evaluate every bullet using this scoring matrix:

- Demonstrates required skill in action: +20 points
- Shows leadership/ownership/initiative: +15 points
- Recency (within last 3 years): +10 points
- Transferable skill relevance: +10 points
- Generic/vague statement with no specifics: -20 points
- Supports the strategic narrative angle: +15 points (NEW)

FOLLOW the experience priority order from the strategic plan.

You MUST follow this MANDATORY inclusion logic:

A) FOUNDATIONAL SKILL RULE (NON-NEGOTIABLE):
When selecting a framework/library, you MUST ALSO select its foundational language:

B) Prioritization order:
1. Skills from the strategy's "mustInclude" list → ALWAYS include (no exceptions)

PROJECTS: The skill graph tells you which projects demonstrate which skills. Select projects that:

- 40-59: Significant gaps. Candidate has some relevant skills but would need to stretch.
